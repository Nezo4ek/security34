Модуль 2: Условные операторы и типы данных

🎯 Условный оператор if-else и логические операторы (and, or, not)

if-else — позволяет выполнять разные блоки кода в зависимости от условия.

if условие:\n    # выполняется, если условие True\nelse:\n    # выполняется, если условие False

Логические операторы:

  • and — True если оба истинны
  • or — True если хотя бы одно истинно
  • not — инвертирует
if age >= 18 and has_ticket:\n    print("Проходите")

📊 Типы данных в Python

int, float, str, max(), min(), abs(), len(), math

import math\nprint(max(10,20,5))  # 20\nprint(abs(-7))       # 7\nprint(math.sqrt(25)) # 5.0
